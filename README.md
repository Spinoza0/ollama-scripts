# Ollama Scripts

Набор скриптов для управления **Ollama** на macOS (Homebrew).

---

## 📋 Описание

Эти скрипты упрощают установку, настройку и управление Ollama — локальной системой для запуска языковых моделей.

Все скрипты используют единую библиотеку `lib.sh`, что обеспечивает согласованную работу и отсутствие дублирования кода.

---

## 📁 Файлы

| Файл | Назначение |
|------|------------|
| `lib.sh` | Библиотека функций для всех скриптов |
| `config.env` | Конфигурация (модель, хост, порт) |
| `install.sh` | Установка Ollama через Homebrew |
| `download-model.sh` | Загрузка модели с управлением сервисом |
| `run-chat.sh` | Запуск режима диалога |
| `run-server.sh` | Запуск сервера (API) |
| `stop.sh` | Остановка сервера |
| `uninstall.sh` | Полное удаление Ollama |
| `status.sh` | Проверка статуса Ollama |

---

## 🚀 Быстрый старт

### 0. Установка скриптов (Homebrew tap)

```bash
brew tap spinoza0/tap
brew install spinoza0/tap/ollama-scripts
```

После установки команды доступны из любой директории **без `./`** и с префиксом `ollama-` (чтобы не конфликтовать с одноимёнными командами других пакетов):

```bash
ollama-install           # установка Ollama
ollama-download-model    # загрузка модели по умолчанию
ollama-run-chat          # режим диалога
ollama-run-server        # запуск сервера API
ollama-stop              # остановка сервера
ollama-status            # проверка статуса
ollama-uninstall         # полное удаление Ollama
```

Конфигурация — в установленном файле `config.env` (см. раздел «Конфигурация»).

> 📌 **Версия из клона репозитория**: скрипты запускаются как `./install.sh`, `./run-chat.sh` и т.д. — без приставки `ollama-`.

> ℹ️ **Подсказки адаптируются автоматически**: вся справка и подсказки внутри скриптов (например, список команд в `status.sh`, хинты «Для запуска…», «Для остановки…») сами показывают правильные имена — `./script.sh` при установке из клона и `ollama-script` при установке через brew.

### 1. Установка Ollama
```bash
# Из клона репозитория:
./install.sh
# Через brew:
ollama-install
```

### 2. Загрузка модели
```bash
./download-model.sh
# Или другая модель:
./download-model.sh qwen3:8b
```

### 3. Использование
```bash
# Режим диалога
./run-chat.sh

# Или режим сервера
./run-server.sh
```

### 4. Проверка статуса
```bash
./status.sh
```

## 📖 Подробное описание скриптов

### `install.sh` — Установка Ollama
- Проверяет macOS и Homebrew
- Устанавливает Ollama через `brew install`
- Показывает следующие шаги

**Использование:**
```bash
./install.sh
```

---

### `download-model.sh` — Загрузка модели
- Проверяет установку Ollama
- Временно запускает сервис (если не запущен)
- Загружает модель
- Останавливает сервис после загрузки (если запускал его)

**Использование:**
```bash
./download-model.sh                    # Модель по умолчанию (qwen3.8:27b-mlx)
./download-model.sh qwen3:8b           # Конкретная модель
./download-model.sh llama3.2           # Другая модель
```

---

### `run-chat.sh` — Режим диалога
- Запускает интерактивный диалог с моделью
- Работает автономно (не требует запущенного сервиса)
- Если модель не загружена — Ollama предложит загрузить её

**Использование:**
```bash
./run-chat.sh                          # Модель по умолчанию
./run-chat.sh qwen3:8b                 # Конкретная модель
```

**В диалоге:**
- Вводите сообщения и получайте ответы
- `/bye` — выход из диалога

---

### `run-server.sh` — Запуск сервера
- Запускает Ollama как сервис (API)
- Проверяет, не запущен ли уже
- Доступно по HTTP: `http://127.0.0.1:11434`

**Использование:**
```bash
./run-server.sh
```

**API endpoints:**
- `GET /api/tags` — список моделей
- `POST /api/generate` — генерация текста
- `POST /api/chat` — чат с моделью

---

### `stop.sh` — Остановка сервера
- Выгружает модели из памяти
- Останавливает сервис Ollama

**Использование:**
```bash
./stop.sh
```

---

### `uninstall.sh` — Удаление Ollama
- Останавливает сервис
- Удаляет все модели
- Удаляет Ollama через `brew uninstall`
- Очищает кэши и конфигурацию

**Использование:**
```bash
./uninstall.sh
```

⚠️ **Требует подтверждения!**

---

### `status.sh` — Проверка статуса
Показывает:
- ✅ Установлен ли Ollama (версия)
- ✅ Статус сервиса (запущен/нет)
- ✅ Активные модели в памяти
- ✅ Установленные модели
- ⚙️ Конфигурацию (модель, хост, порт)
- 📌 Доступные команды

**Использование:**
```bash
./status.sh
```

## ⚙️ Конфигурация

Файл `config.env` содержит параметры:

```bash
MODEL="qwen3.8:27b-mlx" # Модель по умолчанию (MLX для Apple Silicon)
HOST="127.0.0.1"        # Хост сервера
PORT="11434"            # Порт сервера
API_URL="http://..."    # URL API
KEEP_ALIVE="10m"        # Как долго модель остаётся загруженной в памяти
```

Для изменения отредактируйте `config.env`.

> 📌 **При установке через Homebrew** файл `config.env` находится в `/opt/homebrew/etc/ollama-scripts/config.env` и **сохраняется при переустановке/обновлении** формулы. При необходимости можно переопределить путь переменной окружения `OLLAMA_SCRIPTS_CONFIG`.

## 🤖 Доступные модели

### Популярные модели:

|--------|--------|----------|
| `llama3.2` | 3B | Последняя версия Llama от Meta |

### Примеры загрузки:

```bash
./download-model.sh qwen3.8:27b-mlx
./download-model.sh llama3.2
./download-model.sh mistral
./download-model.sh codellama
```

### ✨ MLX-модели для Apple Silicon

**MLX** — фреймворк Apple для запуска LLM на чипах Apple Silicon (M1 и новее), оптимизированный через Metal.

- Для MLX-квантов модели **быстрее** и занимают **меньше памяти**, чем обычные GGUF (примерно на 10–30%).
- Поддержка MLX-движка появилась в **Ollama 0.32+** (превью). Для использования
  обновите Ollama: `brew upgrade ollama`.
- MLX-теги обозначаются суффиксом `-mlx`, например `qwen3.8:27b-mlx` — оптимальная модель по умолчанию для Mac с 24GB+.

Доступные теги `qwen3.8`:

| Тег | Размер | Примечание |
|-----|--------|-----------|
| `qwen3.8:27b-mlx` | 18GB | Рекомендуется (Q4, Mac 24GB+) |
| `qwen3.8:27b-mxfp8` | 32GB | Выше качество, Mac 40GB+ |
| `qwen3.8:27b-mlx-bf16` | 56GB | Практически без потерь, Mac 64GB+ |
| `qwen3.8:27b-q4_K_M` | 18GB | GGUF-версия (кроссплатформенная) |
| `qwen3.8:27b-bf16` | 56GB | GGUF-версия без потерь |

## 📚 Библиотека `lib.sh`

Библиотека содержит 11 функций для использования в скриптах:

| Функция | Описание |
|---------|----------|
| `ollama_is_running()` | Проверка, запущен ли сервис |
| `ollama_get_status()` | Получить статус сервиса |
| `ollama_is_installed()` | Проверка установки Ollama |
| `ollama_get_version()` | Получить версию Ollama |
| `ollama_start_and_wait()` | Запуск сервиса с ожиданием |
| `ollama_stop()` | Остановка сервиса |
| `ollama_model_exists()` | Проверка наличия модели |
| `ollama_get_running_models()` | Список активных моделей |
| `ollama_unload_model()` | Выгрузка модели из памяти |
| `ollama_list_models()` | Список установленных моделей |
| `ollama_rm_all_models()` | Удаление всех моделей |

**Подключение в скрипт:**
```bash
source "./lib.sh"

if ollama_is_running; then
    echo "Сервис запущен"
fi
```

## 🔧 Требования

- **ОС:** macOS (Apple Silicon для MLX-моделей)
- **Менеджер пакетов:** Homebrew
- **Ollama:** 0.32+ (для MLX-моделей)
- **Диск:** ~18 GB (для модели qwen3.8:27b-mlx)
- **Память:** 24 GB+ (для qwen3.8:27b-mlx)

## 📝 Примеры использования

### Полный цикл установки и использования

```bash
# 1. Установка
./install.sh

# 2. Загрузка модели
./download-model.sh

# 3. Проверка статуса
./status.sh

# 4. Запуск диалога
./run-chat.sh

# 5. Запуск сервера (для API)
./run-server.sh

# 6. Остановка сервера
./stop.sh
```

### Проверка перед работой

```bash
# Быстрая проверка статуса
./status.sh

# Если модель не загружена — загрузить
./download-model.sh llama3.2

# Запустить диалог
./run-chat.sh llama3.2
```

---

## ⚠️ Примечания

1. **`brew services`** может показывать статус "error" вместо "started" — это нормальная особенность macOS launchd, сервис работает корректно.

2. **Загрузка моделей** занимает время (5-30 минут в зависимости от размера модели и скорости интернета).

3. **`run-chat.sh`** работает автономно — не требует запущенного сервиса.

4. **`run-server.sh`** требует запущенного сервиса для работы API.
